# 目标定位与工作空间读图

本实验以固定的 PhysVLM 权重、两套已有局部投影层和冻结 Grounding DINO，测量自然语言所指的目标能否被映射到正确的 S-P Map 区域。受控测试包含 48 个独立布局。每个布局交换两种同色目标的位置，得到 96 个视图及 384 个问题。每幅图分别询问两个目标和两个工作空间。可达标签来自目标可见点的关节受限 IK 和 FK 复验，不可达标签来自 URDF 外界证书。第二套测试由作者公开的 Panda 仿真配方生成，包含 55 个此前未见的场景和 96 个问题。

## 候选召回和排序

同一 RGB 和目标描述共享检测结果。经框去重后，受控集的 Top-1 和 Top-3 IoU 达标分别为 88/192 和 192/192。以逐题口径查看 124 个读图错误，其中 40 题选择了可识别的另一物体，84 题的首选框没有与任何标注对象达到身份匹配。身份匹配以最大 IoU 和最低重叠阈值定义。受控集上以 RGB 色度均值乘原检测分数进行重排序，提升 14.58 个百分点，按布局重采样的 95% 区间为 10.42 至 18.23 个百分点。作者配方上同一个策略下降 5.21 个百分点。

作者配方 Top-5 目标身份召回为 82/96，IoU 达标为 62/96。把候选阈值从 0.25 放宽到 0.12，两个计数变为 89/96 和 68/96。在这一批场景上，以标注身份从可用候选中选择并执行地图规则，缺失时回退冻结模型，可答对 86/96。该数值估计现有候选的改进空间。受控样本的证书点相关指标来自同一布局的多个测量，区间使用物理布局重采样。作者配方区间按 RGB 场景重采样。

## 新作者配方验证与冻结语义排序

新场景使用仿真种子 90121 起始。原始 96 条问题中有两条的 RGB、地图和问题一致，标签相反。这两条问题在评估前排除，余下 94 条，开发、旧测试与新测试的 RGB 哈希互不重叠。

新场景上的 Top-5 目标身份召回由阈值 0.25 时的 82/94 升到阈值 0.12 时的 90/94。对应 IoU 达标由 56/94 升到 64/94。后续在相同的五个去重候选框中比较 Grounding DINO 原始得分、冻结 CLIP 裁剪与短语余弦相似度，以及二者的标准化得分融合。融合权重 0.50 由作者配方开发集锁定。

| 候选排序 | 目标身份正确 | IoU ≥ 0.5 | 作者配方地图读图正确 | 受控四问全对 |
| --- | ---: | ---: | ---: | ---: |
| 原检测分数 | 46/94 | 30/94 | 63/94 | 12/96 |
| 冻结 CLIP | 50/94 | 35/94 | 62/94 | 0/96 |
| 开发集选择的分数融合 | 53/94 | 37/94 | 64/94 | 0/96 |

新作者配方上的冻结全图 PhysVLM 答对 67/94。受控集的两种 CLIP 排序虽然分别答对 272/384 和 262/384，但四问全对均为零。该对照说明正确身份、框形状与两张地图上的读图表现需要同时验收。当前冻结语义排序只提供候选定位基线。

## 复现

使用 README 的上游版本和 CPU 仿真环境。Grounding DINO 使用单独的 Transformers 4.57.1 环境与 `IDEA-Research/grounding-dino-tiny` 的 `a2bb814dd30d776dcf7e30523b00659f4f141c71` 版本。PhysVLM 推理使用 README 中的模型版本和依赖。

```bash
"$cpu_python" study/generate_grounding_study.py "$root/grounding-dev" --count 12 --seed 83519
"$cpu_python" study/generate_grounding_study.py "$root/grounding-test" --count 48 --seed 67231
"$cpu_python" study/prepare_official_control.py "$root/source-test" --seed-start 88023 --per-label 48 --max-scenes 128 --robot PANDA
"$detector_python" study/detect_grounding_targets.py "$root/grounding-test/manifest.json" "$detector_checkpoint" "$root/boxes.json"
python study/grounding_readout.py prepare "$root/grounding-test/manifest.json" "$root/boxes.json" "$root/grounding-crops"
python study/evaluate_target_alignment.py predict --free-only --model model --alignment "$root/grounding-test/manifest.json" --output "$root/frozen"
python study/evaluate_target_alignment.py predict --free-only --model model --alignment "$root/grounding-crops/predicted/manifest.json" --checkpoint "$root/tune-17/best.pt" --output "$root/grounding-projector17"
python study/grounding_readout.py score "$root/grounding-crops/regions.json" "$root/frozen/alignment.jsonl" "$root/summary.json" --prediction "predicted-projector17=$root/grounding-projector17/alignment.jsonl"
python study/audit_grounding_candidates.py "$root/grounding-test/manifest.json" "$root/boxes.json" "$root/candidate-audit.json"
```

作者配方评测使用 `--official` 和 `official.jsonl`。色度实验先通过 `rerank_grounding_targets.py rgb-objectness` 生成新框，再使用同一读图流程。

冻结语义对照使用 `openai/clip-vit-base-patch32` 的 `3d74acf9a28c67741b2f4f2ea7635f0aaf6f0268` 版本和检测器环境。先运行 `study/score_region_semantics.py` 保存前五个去重候选的图文余弦分数，再用 `study/rerank_grounding_targets.py semantic --weight` 选择权重为 0、1 或开发集选定的 0.5 的排序。三组输入使用同一候选阈值和地图读图规则。
