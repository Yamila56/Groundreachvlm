# GroundReach 后续实验设计

**状态：待执行。** 当前 133,152 参数点 token 适配器在干净输入下达到与匹配像素规则相同的成绩。有一次配对测试中，固定 8 像素偏移使点适配从 126/128 降到 116/128，像素规则维持 126/128。下一步研究问题是：**当定位有误差时，错误主要来自选点跨过可达边界，还是正确区域内的点特征读出不稳定？** [当前点适配与扰动结果](关系指代与可达性实验报告.md#point-conditioned-token-训练小试)

## 第一阶段：近边界诊断，复用已有权重

- **数据与认证。** 保持静态 Panda、可见标记和现有物理任务。生成不同物体与锚点组合的新布局，覆盖近边界和区域内部，保留真实标签翻转和标签不变的成对场景。用真实点相对显示地图边界的带符号距离分层，同时对原点和偏移点独立重算 IK/FK 或 URDF 证书。显示地图的颜色边界只用于采样和分层。证书未知的情况保留分母并单列。
- **受控定位误差。** 同一目标在配对地图上使用相同位移。以 0、2、4、8、16、32 像素为候选测试幅度，并跨方向覆盖沿边和跨边的位移。用冻结定位器在开发布局上的真实误差检查偏移分布，并保留真实缺点、错点和错目标三类结果。有自动点的样本与合成偏移样本各自汇报。
- **拆开查点与裁剪。** 一组固定原裁剪，只移动查点，测局部特征选择。另一组根据偏移重算同步裁剪，测部署时的联合敏感性。固定裁剪的检验限定两点都在裁剪窗内，并报告覆盖。点 token 与像素规则使用完全一致的输入点和地图。
- **区分两类失败。** 在原点和偏移点都取得证书时，按是否跨越认证类别分组。保持类别的位移主要检查读图稳定性。跨类别时同时按真实查询点和实际读取点评分，识别正确读错点与读图错误。对近边界确认集同时报告真值点端的读出上界和自动点端到端结果。
- **验收口径。** 主要指标是近边界、未跨类别样本上的地图切换双答正确率，其余看目标切换、标签不变对、总体准确率、完整布局和定位覆盖。对同一场景、目标和多方向位移保留配对关系，按独立布局重采样。在开发集确定边界距离分层和最小有意义改善，冻结后使用另一批认证布局确认，避免把重复扰动当作新样本。

## 第二阶段：小范围改变特征采样

若真值点或未跨类别的小偏移仍有可复现的读图损失，先比较现有单点采样与四邻域双线性插值。两者保持冻结主干、可训练参数 **133,152**、同样的裁剪、题序和训练预算。先用现有头看冻结诊断，再在同一预算下重训两种读出，以区分输入分布变化和采样方法的效果。

`3×3` 均值和距离加权池化只在结果显示邻域信息有用时补做。所有版本都保留同一点的确定性像素读出，检查平滑会不会模糊真实边界。进入下一步需要近边界未跨类别样本的配对改善，并让干净输入、真正跨类别的响应和目标切换满足事先锁定的保留界限。若主要误差来自选错目标或查点跨界，优先改善候选与定位的置信度、弃答和目标点校准，继续使用当前点适配器。LoRA 和复杂融合暂缓。

## 后续边界

定位鲁棒性得到确认后，先做同一对象上的多点几何认证，比较每点分类及区域可达比例，测试区域内可达与不可达混合的布局。再逐步移除显式标记，从可定义真值的顶部、边缘和部件开始，沿用真值点与自动点对照。姿态、夹爪尺寸、碰撞和轨迹需要新的任务定义与独立证书。当前版本的适配器、证书、预测和 CPU 回放已经归档。公开发布前还需核查素材和上游许可，固定依赖与模型来源，并在新环境验证完整推理链。
